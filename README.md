# English Quest — Остров слов

Игра для третьеклассника: учим английский через мини-игры, звёзды и приключение на острове.

## Как запустить

```bash
npm install
npm run dev
```

Откроется страница в браузере (обычно http://localhost:5173).

## Что внутри

- **9 тем**: звери, цвета, числа, семья, еда, школа, дом, действия, одежда
- **Mastery + интервальное повторение** по каждому слову
- **Ошибки возвращаются** в том же раунде
- **Честное аудирование**: варианты без русского, открываются после прослушивания
- **Фразы по темам**, согласованные со словарём
- **5 мини-игр**: угадай слово, слушай, собери слово, найди пару, собери фразу
- Озвучка British English (`en-GB`), звуки UI, адаптивная вёрстка
- Разблокировка тем: 8⭐ + 45% знания предыдущей темы (анти-фарм звёзд)
